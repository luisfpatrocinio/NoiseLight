O Semáforo do Barulho com ESP32

Um dispositivo inteligente com microfone analógico MAX4466 e 3 LEDs gigantes de 10mm que monitora o nível de som da sala de aula em tempo real, incentivando a concentração e a convivência escolar.

Verde: Silêncio (Estudo & Concentração)
Amarelo: Atenção (Conversas em grupo)
Vermelho: Alerta (Barulho Excessivo / Pisca)

🔌 Esquema de Fiações & Montagem Física

Para caber em protoboards comuns, o ESP32 foi montado utilizando apenas a fileira do pino 3V3. Veja a rota de cada cabo jumper e a função de cada componente:

⚡ Alimentação do Sensor Fio Vermelho
Pino 3V3 (ESP32) → VCC (MAX4466)

Fornece 3.3V regulados com baixo ruído de chaveamento, garantindo leituras estáveis de áudio no conversor ADC.

🔌 Terra Comum (GND) Fio Preto
Pino GND (ESP32) → Barramento Azul (-)

Fecha o circuito elétrico interligando o negativo do módulo de som e os 3 cátodos (pernas curtas) dos LEDs.

🎙️ Sinal Analógico de Áudio Fio Laranja
OUT (MAX4466) → Pino D4 (GPIO 4)

Envia as ondas acústicas em tempo real para a entrada analógica ADC2 do microprocessador do ESP32.

🟢 LED 10mm Verde (Silêncio) Fio Verde
Pino D18 (GPIO 18) → Resistor 220Ω → LED

Sinaliza ambiente silencioso e concentração. O resistor limita a corrente elétrica em ~6mA para proteger o LED.

🟡 LED 10mm Amarelo (Atenção) Fio Amarelo
Pino D19 (GPIO 19) → Resistor 220Ω → LED

Indica conversas moderadas na sala. Alerta visual suave antes de o barulho se tornar excessivo.

🔴 LED 10mm Vermelho (Alerta) Fio Roxo
Pino D21 (GPIO 21) → Resistor 220Ω → LED

Acionado quando o som atinge o limiar crítico. Pisca em modo de alerta estroboscópico com retenção de 1,5s.

💡 Por que usamos resistores de 220Ω nos LEDs de 10mm? (Lei de Ohm)

O ESP32 envia 3.3 Volts em cada pino digital. Como o LED precisa de apenas cerca de 2.0 Volts, o resistor de 220Ω absorve o excesso de voltagem e limita a corrente em um valor seguro ($I = V/R \approx 6\text{ a }10\text{ mA}$). Sem o resistor, o LED queimaria em frações de segundo!

💻 Visualização do Código do ESP32

Navegue pelos blocos essenciais do firmware em C++ / Arduino. Veja como o ESP32 lê o sinal analógico, toma decisões e controla os LEDs:

src/main.cpp • C++ / PlatformIO 
// --- CÓDIGO COMPLETO DO FIRMWARE (src/main.cpp) ---
#include <Arduino.h>

const int PINO_SENSOR_SOM   = 4;  // OUT do MAX4466 (Entrada Analógica D4)
const int PINO_LED_VERDE     = 18; // LED 10mm Verde (D18)
const int PINO_LED_AMARELO   = 19; // LED 10mm Amarelo (D19)
const int PINO_LED_VERMELHO  = 21; // LED 10mm Vermelho (D21)

int limiarAmarelo  = 900;  // Acima deste valor passa para Amarelo
int limiarVermelho = 2200; // Acima deste valor passa para Vermelho

void setup() {
  Serial.begin(115200);
  analogReadResolution(12); // ADC do ESP32: 0 a 4095
  analogSetPinAttenuation(PINO_SENSOR_SOM, ADC_11db);

  pinMode(PINO_LED_VERDE, OUTPUT);
  pinMode(PINO_LED_AMARELO, OUTPUT);
  pinMode(PINO_LED_VERMELHO, OUTPUT);
}

void loop() {
  // Amostragem Pico-a-Pico durante 50ms
  int amplitude = medirAmplitudePicoAPico(50);
  atualizarSemaforo(amplitude);
}
💡 Explicação Didática

Este é o firmware completo gravado no ESP32. Ele configura o conversor analógico-digital (ADC) para ler o microfone analógico MAX4466 no pino D4 e controla as saídas digitais D18, D19 e D21 para acionar os LEDs de 10mm.
