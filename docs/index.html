Seção 2

⚡ Como o ESP32 Controla os LEDs?

Veja a corrente elétrica (fluxo ordenado de elétrons) saindo dos pinos GPIO do ESP32, passando pelo resistor protetor e iluminando o LED.

CORRENTE ATIVA NO GPIO 25
⚡ Tensão no Pino: 3.3 V (HIGH)
💡 Queda no LED: 2.0 V
🌊 Corrente Resultante: 5.9 mA

💡 Por que usamos o Resistor?

O ESP32 fornece 3.3 Volts, mas o LED precisa de cerca de 2.0 Volts. Sem o resistor, a corrente elétrica seria tão alta que queimaria o filamento do LED em frações de segundo! O resistor de 220 Ω funciona como um redutor de velocidade, mantendo a corrente segura em aproximadamente 6 miliamperes.

🔬 O que é Nível Lógico (HIGH e LOW)?

Quando o código executa digitalWrite(pino, HIGH), o ESP32 fecha uma chave interna conectando o pino aos 3.3V, fazendo os elétrons correrem. Quando executa LOW, ele desliga a energia (0V).

Seção 3

💻 O Código do ESP32 Passo a Passo

Descubra as principais funções da programação do semáforo. Clique em cada conceito abaixo para ver como o código em C++ / Arduino foi construído.

src/main.cpp C++ (Arduino / ESP32) 
// 1. Função executada uma única vez ao ligar o ESP32
void setup() {
  Serial.begin(115200); // Comunicação com o computador

  pinMode(PINO_SENSOR_SOM, INPUT);  // Sensor de som envia dados para o ESP32
  pinMode(PINO_LED_VERDE, OUTPUT);   // Pino envia corrente para o LED Verde
  pinMode(PINO_LED_AMARELO, OUTPUT); // Pino envia corrente para o LED Amarelo
  pinMode(PINO_LED_VERMELHO, OUTPUT);// Pino envia corrente para o LED Vermelho
}
💡 Como isso funciona?

No setup(), definimos o papel de cada pino. O pino do microfone é configurado como INPUT (entrada de dados auditivos) e os pinos dos LEDs são configurados como OUTPUT (saídas capazes de fornecer 3.3V para acender os componentes).
